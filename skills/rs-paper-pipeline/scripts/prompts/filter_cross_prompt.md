## 核心方向

1. 多模态显著目标检测：不限于 RGB-T，也包括 RGB-D、RGB-NIR、RGB-Event、音视频显著性及其他视觉模态组合。
2. 多模态视觉学习：跨模态/多传感器融合、对齐与非对齐建模、缺失模态、模态不确定性、鲁棒融合、参数高效适配。
3. 多视角与多目标感知：多目标跟踪、跨相机关联、跨视角匹配、ReID，尤其关注复杂或非对齐场景。
4. 无人机视觉：UAV/Drone/低空或航拍场景中的检测、跟踪、分割、ReID、定位、导航、小目标感知和多机协同视觉。
5. 免训练开放集分割：training-free / annotation-free / zero-shot 的 open-vocabulary、open-set 或 open-world 语义/实例/全景分割，重点关注冻结视觉语言模型、视觉基础模型、扩散模型或 SAM 的推理时适配，以及遥感、航拍、UAV 和多模态场景迁移。

## 保留标准

- 标题或摘要必须出现明确的视觉任务、视觉传感器、图像/视频数据或视觉方法证据。
- 对显著目标检测，只要任务明确，可覆盖任意单模态或多模态设置；优先保留多模态、弱对齐、鲁棒性和高效学习工作。
- 对一般多模态论文，方法贡献应集中在视觉模态融合、对齐、缺失模态、不确定性或跨模态表征，并对检测、分割、跟踪、显著性等视觉任务有直接价值。
- 多模态范围包括但不限于 RGB-X、可见光-红外/热成像、RGB-D、相机-LiDAR/雷达、RGB-Event、音视频、跨光谱、多光谱/高光谱以及视觉-语言感知。
- 对多光谱、高光谱、遥感和机器人论文，若核心方法对多模态融合、弱对齐、缺失模态、显著性、检测、分割或跟踪具有直接可迁移价值，可以保留。
- 对无人机论文，必须以图像、视频或视觉感知为核心，而不是只把 UAV 当通信、控制或网络平台。
- 无人机范围包括低空视觉、航拍/俯视图像、小目标感知、多无人机协同感知、视觉导航、定位、建图和跨视角关联。
- 对免训练开放集分割，必须明确不需要下游训练、微调或任务标注；允许使用冻结的预训练基础模型与推理时优化。优先保留空间细节恢复、边界优化、跨域泛化、类别校准、上下文推理以及遥感/多模态扩展工作。
- 自动驾驶或机器人论文只有在多传感器融合、模态鲁棒性或跨模态对齐方法具有明显可迁移价值时才保留。

## 排除标准

- 纯 NLP、情感分析、推荐系统、通用 agent、纯语音/音频生成或纯文本多模态论文。
- 只使用“multimodal”措辞，但没有视觉模态、视觉任务或视觉评测证据的论文。
- 纯遥感分类、土地覆盖、气象、测绘论文，除非明确涉及无人机视觉、显著性、多模态融合或目标跟踪。
- UAV 通信、路径规划、飞控、无线网络、边缘计算论文，若没有核心视觉贡献则排除。
- 仅做单张自然图像分类且与上述方向没有方法联系的论文。
- 医疗、社交媒体或通用多模态论文若只是应用场景相似、没有可迁移的视觉融合/对齐方法贡献，也应排除。
