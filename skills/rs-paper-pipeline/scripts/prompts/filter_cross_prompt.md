## 核心方向

1. 多模态视觉学习：融合与跨模态表征、对齐/非对齐建模、缺失模态与鲁棒学习、多模态检测/分割/跟踪、视觉语言模型与高效适配。显著目标检测（SOD）和伪装目标检测（COD, camouflaged / concealed object detection）作为本方向的子任务，不再单列主方向。
2. 多视角与多目标感知：多目标跟踪、多相机/跨相机跟踪、跨视角匹配与 ReID、多视角几何与三维感知、时空关联与鲁棒感知。
3. 无人机视觉：航拍目标检测、分割与场景理解、跟踪与跨视角检索、视觉定位/导航/建图、多机协同、多模态及复杂环境感知。
4. 免训练开放集分割：明确 training-free 的开放词汇/开放集/开放世界语义、实例或全景分割；包括冻结基础模型推理、空间与边界细化、上下文/原型/类别校准、跨域与遥感扩展。零样本或无标注不必然意味着免训练，必须有不需要下游训练或微调的证据。

这些方向允许交叉，不能只按首个关键词判定。研究雷达的完整主方向与子方向定义位于 research_taxonomy.json；命中多个方向仍只保留一条论文记录。

## 保留标准

### 拓展阅读（第五个展示方向）

未直接命中四个核心方向时，可保留以下相邻工作：单 LiDAR/雷达或点云的三维检测与分割；对视觉感知有价值的域泛化、损坏鲁棒性和合成数据增强；有可迁移方法的卫星/多光谱检测与分割；具有三维记忆、几何一致性或跨视点空间建模的视频世界模型。

必须能从摘要指出具体的可借鉴方法、评估协议或几何建模机制，不能只凭 LiDAR、遥感、鲁棒或 world model 等词保留。普通应用堆叠、纯生成质量改进、纯传感器硬件或与视觉感知无关的工作仍排除。核心方向优先，拓展阅读不是放宽刊会质量门槛，也不为凑数量保留论文。

### 通用与核心方向标准

- 标题或摘要必须出现明确的视觉任务、视觉传感器、图像/视频数据或视觉方法证据。
- 对显著目标检测，只要任务明确，可覆盖任意单模态或多模态设置；优先保留多模态、弱对齐、鲁棒性和高效学习工作。
- 对伪装目标检测/分割（COD），保留以发现或分割伪装/隐蔽目标为核心的视觉方法，优先多模态、RGB-D/RGB-T、文本引导、鲁棒性及高效推理；相关单模态基础方法可作为本组子任务收录，但不能将其称为多模态方法。不能仅凭 COD 缩写保留。
- 对一般多模态论文，方法贡献应集中在视觉模态融合、对齐、缺失模态、不确定性或跨模态表征，并对检测、分割、跟踪、显著性等视觉任务有直接价值。
- 多模态范围包括但不限于 RGB-X、可见光-红外/热成像、RGB-D、相机-LiDAR/雷达、RGB-Event、音视频、跨光谱、多光谱/高光谱以及视觉-语言感知。
- 对多光谱、高光谱、遥感和机器人论文，若核心方法对多模态融合、弱对齐、缺失模态、显著性、检测、分割或跟踪具有直接可迁移价值，可以保留。
- 对无人机论文，必须以图像、视频或视觉感知为核心，而不是只把 UAV 当通信、控制或网络平台。
- 无人机范围包括低空视觉、航拍/俯视图像、小目标感知、多无人机协同感知、视觉导航、定位、建图和跨视角关联。
- 对免训练开放集分割，必须明确不需要下游训练或微调；允许冻结的预训练基础模型及不更新模型参数的推理时优化，不能把测试时梯度更新当作免训练。仅有 zero-shot、annotation-free、SAM 或 CLIP 字样不足以确认。优先保留空间细节恢复、边界优化、跨域泛化、类别校准、上下文推理及遥感/多模态扩展。
- 自动驾驶或机器人论文须满足核心方向标准，或符合上述拓展阅读的方法借鉴标准；不要求单传感器参考方法被称作多模态。

## 排除标准

- 纯 NLP、情感分析、推荐系统、通用 agent、纯语音/音频生成或纯文本多模态论文。
- 只使用“multimodal”措辞，但没有视觉模态、视觉任务或视觉评测证据的论文。
- 纯遥感分类、土地覆盖、气象、测绘论文，除非明确涉及无人机视觉、显著性、多模态融合或目标跟踪。
- UAV 通信、路径规划、飞控、无线网络、边缘计算论文，若没有核心视觉贡献则排除。
- 仅做单张自然图像分类且与上述方向没有方法联系的论文。
- 医疗、社交媒体或通用多模态论文若只是应用场景相似、没有可迁移的视觉融合/对齐方法贡献，也应排除。
